Features

Everything you need to run a class register

Designed for daily use — open it every morning, close it every evening.

Morning & Lunch Attendance

Mark two sessions daily per class. One tap per student. Mark all at once or individually.

Class-wise Structure

Separate registers for Class 6, 7, 8, 9, and 10. Switch between classes instantly.

Reports & Analytics

Attendance percentage per student. Pie chart and horizontal bar chart. Color coded.

Student Profiles

Apaar ID, PAN, DOB, parent details, address, admission number — all in one place.

PIN + Password Security

Login password and animated PIN keypad. Two layers of protection.

Firebase Backend

All data stored in Firebase Firestore. Works offline and auto-syncs when back online.
